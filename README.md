# QQ 经典农场 自动收菜 / 偷菜（电脑版 QQ）

原理：截取农场小程序窗口 → 用 OpenCV 模板匹配找按钮/图标 → 模拟鼠标点击。
不碰游戏协议、不需要账号密码或登录 code，和你自己用鼠标点没有区别。

> 运行时脚本会占用鼠标，建议挂机时不要用电脑。
> 紧急停止：**把鼠标快速甩到屏幕左上角**，或在命令行按 **Ctrl+C**。
> 自动化操作可能违反游戏用户协议，有被限制/封号的风险，请自行斟酌，建议用小号先试。

代码仓库：https://github.com/xujingxuan623-cloud/work （本地改动会自动同步上来）

## 0. 最简单的用法：图形界面

模板已经截好的情况下，**双击 `启动农场助手.bat`**（或桌面上的「农场挂机助手」快捷方式）打开界面。
界面分「运行情况」（各项统计 + 彩色日志）和「设置」两页；图标在 `assets/`，由 `tools/make_icon.py` 生成。

想自己建一个带图标的快捷方式：目标填 `pythonw.exe "<项目路径>\farm_gui.py"`，起始位置填项目文件夹，图标选 `assets\farm.ico`。

- **▶ 开始挂机**：每隔设定的分钟数跑一轮（收菜 + 偷菜），一直循环
- **■ 停止 / F10**：随时停止（脚本在操作鼠标时直接按 F10 最方便）
- **⟳ 立即跑一轮**：停止状态下只跑一轮；挂机中则跳过等待马上开始下一轮
- 挂机期间会阻止电脑休眠和自动锁屏；某一轮出错只记日志，下一轮继续
- 日志按天保存在 `logs/` 文件夹

长期挂机注意：
- 农场窗口不要最小化、不要被其他窗口挡住，**不要锁屏**（Win+L 后截图是黑的）
- 显示器可以关，但电脑不能睡眠（界面里那个勾选项会处理）
- 挂机时别动鼠标；要用电脑就先按 F10 停止

## 1. 安装

```bash
pip install -r requirements.txt
```

## 2. 确认窗口标题

在 QQ 里打开「QQ经典农场」小程序，然后：

```bash
python farm_bot.py --list-windows
```

找到农场窗口那一行，如果标题不是「QQ经典农场」，把 `config.ini` 里 `[window] title` 改成标题里的一段文字。

## 3. 截模板（最关键的一步）

游戏界面会更新、每个人分辨率也不同，所以按钮图标需要你在自己电脑上截一次。
先把游戏切到对应画面，再运行（`--delay 3` 可以给你 3 秒切画面）：

```bash
python capture_template.py ripe
```

弹出截图后，用鼠标框住图标 → 回车保存。需要的模板：

> 下表模板已按 452x843 的窗口截好放在 `templates/` 里（Version 1.15.0.2）。游戏更新或窗口大小变了再重截。

| 角色名 | 截什么 |
|---|---|
| `harvest_all` | 自家「一键收获」按钮 |
| `ripe` | 成熟作物上的「可摘」气泡（自家、好友家通用） |
| `friends` | 自家右下角「好友」按钮 |
| `visit` | 好友列表里的「拜访」按钮 |
| `panel_close` | 好友列表右上角的 ✕ |
| `friend_steal` | 好友家底部好友栏，头像右上角「戴墨镜的小手」= 可以偷 |
| `steal_all` | 好友家「一键偷取」按钮 |
| `go_home` | 好友家右下角「回家」按钮 |
| `empty_plot` | 自家空地上的白色小手 |
| `empty_tile` | 空地块中间（紫色、黄色各一张） |
| `reconnect` | 「网络连接超时」里的「重新连接」 |
| `relogin` | 「账号已在其他地方登录」里的「重新登录」 |
| `task_icon` | 左下角任务条上的书本图标 |
| `milktea_icon` / `milktea_claim` / `milktea_take` / `milktea_close` / `milktea_back` | 奶茶店入口、领取收益、领取按钮、关闭、返回 |
| `farm_all` | 「一键务农」按钮 |
| `friend_help` | 好友栏头像右上角的「小农夫」 |
| `close` | 弹窗的关闭 / 确定按钮（目前还没截，遇到挡路的弹窗再补） |
| `steal_ripe` | 可选，好友家可偷作物图标（不截就用 `ripe`） |

截图技巧：
- **只框图标本身**，尽量别带进背景（背景会变，带进去容易认不出）。
- 同一个东西有多种样子（比如不同作物的成熟图标），就多截几张，会自动存成 `ripe_2.png`、`ripe_3.png`…
- 截完模板后**不要再改变窗口大小**，否则要调 `scales` 或重截。

## 4. 测试识别

```bash
python farm_bot.py --test
```

会列出每个模板的最高相似度，并把标注结果存到 `debug/test_result.png`。
- 该认出来却没认出来 → 在 `config.ini` 的 `[match]` 里把这个角色的阈值调低，如 `ripe = 0.72`
- 认错地方 → 调高阈值，或重截一张更“干净”的模板

## 5. 运行

```bash
python farm_bot.py --once
```

先跑一轮看看效果，没问题再去掉 `--once` 长期挂机（默认每 10±3 分钟一轮）：

```bash
python farm_bot.py
```

## 配置说明（config.ini）

- `do_harvest` / `do_steal`：开关收菜、偷菜
- `round_interval_min` / `interval_jitter_min`：每轮间隔和随机浮动
- `quiet_hours`：休息时段，如 `1-7`
- `max_friends_per_round`：每轮最多偷几家
- `[friend_list_scroll]`：好友列表的翻页拖动方向（竖向/横向列表要对应修改）
- `debug = true`：每次识别都存标注截图到 `debug/`，排查问题用

## 种菜流程说明

脚本靠空地块中间“没有种子堆、没有苗”来认空地（模板 `empty_tile`，紫色地、黄色地各一张；
偶尔出现的白色小手 `empty_plot` 作为补充）。脚本点这块空地 → 弹出种子栏 →
用 OCR（RapidOCR，离线）读出每种种子上方的数量 → 点数量最多的那种（`[plant] seed_choice = first` 可改成选第一个）。
游戏里「一键种植」默认勾选，选一次种子就种满所有空地；没勾选也没关系，脚本会一块一块种。
种子栏里读不到数字 = 没种子，脚本会关掉种子栏，不种。

> 注意：装 `rapidocr` 会顺带装一个无界面版 OpenCV，导致截模板工具的框选窗口打不开。装完执行：
> `pip uninstall -y opencv-python-headless` 再 `pip install --force-reinstall --no-deps opencv-python`

## 务农

- **自家务农**（默认开）：地里有草 / 虫 / 缺水时，底部按钮会变成「一键务农」（模板 `farm_all`），每轮收菜后点它。
- **帮好友务农**（默认关）：好友家底部好友栏头像右上角的「小农夫」（模板 `friend_help`）表示需要帮忙，
  脚本会挨个进去点「一键务农」。和偷菜可以同时开：一个好友同时可偷又要帮忙，只进一次、两样都做。

每轮顺序：确认在自家 → 收菜 → 自家务农 → 种菜 → 去好友家（偷菜 / 帮忙）→ 回家。

## 奶茶店收益

默认每 60 分钟一次：点右上角「奶茶热销中」→ 左边「领取收益」→ 「累计收益」窗口里的「领取」
（黄色才点，灰色说明暂时没收益）→ 点空白处关掉「恭喜获得」→ 返回农场。
收益最多攒 48 小时，所以间隔不用太短。不会点「一键爆单」。

## 每日任务

每轮最后检查左下角「等级提升至…」条上的书本（模板 `task_icon`）：书本右上角有红色数字角标时
（另外每 2 小时兜底一次），打开任务面板，用 OCR 找「领取」按钮从上往下挨个点，领完关掉面板。
不会点「前往」（成长任务跳转）和「已完成」。

## 掉线 / 弹窗恢复

每轮开始前会确认画面在自家农场：
- 「账号已在其他地方登录」→ 点「重新登录」（模板 `relogin`）。可设置被挤后等 N 分钟再登录，
  自己在手机上玩的时候设成 30 之类，免得脚本马上把手机挤下去；也可以关掉自动重新登录
- 「网络连接超时，是否重新连接？」→ 自动点「重新连接」（模板 `reconnect`）
- 画面整体变暗（有弹窗遮罩）→ 用 OCR 找「重新连接 / 重启 / 知道了 / 确定」等按钮点掉；画面上有「购买 / 钻石 / 支付」时不点「确定」
- 在好友家 → 点回家；开着面板 → 点 ✕
- 都不行就截图到 `debug/unknown_*.png`，2 分钟后再试

## 偷菜流程说明

好友列表里看不出谁可偷，但好友家底部的好友栏会在头像右上角显示「戴墨镜的小手」。所以流程是：

自家点「好友」→ 拜访列表第一个人进入好友家 → 一键偷取 → 在底部好友栏找带墨镜小手的头像，从左到右逐个点进去偷 → 当前可见的都处理完就把好友栏往左拖，拖不动就结束 → 回家。

偷不了的人（被狗咬、次数用完）标记可能还在，脚本会记住他的头像，同一轮不会反复点。
